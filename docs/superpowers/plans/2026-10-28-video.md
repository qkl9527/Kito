# 视频伙伴实现计划

**目标：** 用 Rust 封装 FFmpeg / ffprobe，让常见视频处理通过清楚的子命令完成，并提供详尽中文说明。

**决策：** 用户已授权自主决定并直接实现。保留当前工作区（仓库内容尚未提交），不创建依赖已有提交的 worktree，不执行 commit、推送或发布。参考 MoviePy 的剪片、拼接与音轨处理思路，不引入 Python 运行时。

**架构：** `src/video/cli.rs` 定义命令；`probe.rs` 负责后端与元数据；`filters.rs` 负责严格时间/尺寸解析及滤镜；`mod.rs` 规划参数、执行和校验。复用 `backend::run_process` 与文件安全策略，视频保持磁盘流式处理，不整文件载入内存。

**能力范围：** doctor/info、convert、compress、trim、resize、crop、rotate、speed、concat、mute、audio extract/replace/volume、snapshot、gif。MP4/MKV/MOV 使用 H.264/AAC，WebM 使用 VP9/Opus；提供易读质量档位、dry-run、JSON、超时。只处理首个非封面视频轨与首音轨；不提供 stream copy、字幕烧录或完整时间线编辑器。

**安全和语义：** 仅本地普通文件；参数数组调用；拒绝同文件及符号链接输出；默认不覆盖。输出在同目录临时文件生成，ffprobe 检查所需轨道并完整解码后原子发布；失败保留已有目标。重编码不声称无损或一定变小。拼接统一画布/帧率/音频格式，缺音轨补静音；配乐以视频时长为准。

- CLI 帮助测试先行：4 项因缺少 video 命令按预期失败。
- 本机可用 FFmpeg / ffprobe 8.1；官方 FFmpeg 网页暂时无法访问，滤镜语义以本机 `ffmpeg -h` 及真实素材验证；MoviePy 官方组合文档已查阅。
- 用户追加音乐处理需求：增加独立音频 convert/trim/concat/mix/speed/fade/normalize，保留音轨 extract/replace/volume；输出统一 48 kHz 立体声并明确重采样和量化边界。
- 同步回归发现各流分别归零导致延迟音频被提前播放：新增流 start_time，以视频起点为零保留音轨偏移，前导静音或裁除超前段。延迟/超前/非零容器起点真实测试通过。
