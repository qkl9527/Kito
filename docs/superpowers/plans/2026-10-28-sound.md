# Echo 艾可 · 声音创作工具实施计划

> 执行方式：按 executing-plans 的验证流程，独立模块并行实现；用户已授权自行决定并完整实现，不再等待方案确认。仓库无 HEAD，在当前工作目录增量开发，不 commit、推送或发布。

**目标：** 给不熟悉合成器的用户提供一条命令生成音效、旋律、和弦与鼓点的入口。

**架构：** Rust 内置离线合成器，无外部运行时或新依赖。`sound` 入口归属 Echo 艾可 · 声音伙伴（音效师），不增加角色名别名。参考 Tone.js 的音名、节拍和乐器抽象，以及 sfxr 的场景预设，优先让默认参数可用。只创作新声音，不读取或加工现有音频；音频转码、剪裁、提取、音量调整继续由视频伙伴处理。

**技术：** Rust / clap / serde；PCM16 单声道 WAV；Standard MIDI File type 0；共享 io_args 输入、files::publish 原子输出。

## 接口与行为

- `sound presets [--json]`：列出 8 个音效 `notify/success/error/coin/jump/laser/explosion/whoosh`、5 个乐器 `sine/soft/bell/pluck/chip` 与 3 个鼓型 `basic/house/hiphop`。
- `sound sfx <PRESET> [-o PATH] [--duration SECONDS] [--pitch SEMITONES]`：默认 `<preset>.wav`，时长默认按场景配置。
- `sound tone [PITCH= A4] [--duration 1] [--instrument sine]`：PITCH 为 C4、F#4、Bb3 或 440/440Hz，默认 tone.wav。
- `sound melody [SCORE | --file PATH|-] [--bpm 120] [--instrument soft] [--repeat 1]`：共享原始输入，默认 melody.wav；输出扩展名 .mid/.midi 切换 MIDI，否则只接受 .wav。
- 乐谱用空白分隔事件，`C4:1 D4:0.5 C4+E4+G4:2 R:1`；未指定拍数默认为 1；`|` 可作为独立分隔符；支持升降号和 MIDI 0..127 的八度，12 平均律 A4=440。拍数 1/16..64、BPM 20..400、重复 1..64、最多 4096 个发声音符、和弦最多 8 音，总长最多 120 秒；时长用 480 ticks/beat 量化，拒绝非整 tick，不静默修正。允许纯休止符。
- `sound beat [PRESET=basic] [--kick PATTERN] [--snare PATTERN] [--hat PATTERN] [--bpm 120] [--bars 4]`：每个模式固定 16 格，x/X 发声、-/ . 休止（实现只接受 `-` 和 `.`，无空白）；一小节固定 4/4。自定义轨替换所选预设对应轨。默认 beat.wav，末尾不追加尾音。
- WAV 共同参数：`--sample-rate 44100`（22050/44100/48000）、`--volume 0.7`（0..1）、`--seed 0`（确定性噪声）；所有生成命令 `-o/--output`、`--overwrite`、`--dry-run`、`--json`。MIDI 不接受显式 WAV 专用参数或乐器参数，避免暗中忽略；MIDI 固定 program 0、velocity 100。
- `--dry-run` 完成输入、资源、输出路径校验并给出报告，不合成、不创建目录或文件；JSON 只输出一个结构化对象，错误退出且 stdout 为空。
- 声音渲染包含起落包络和混音峰值衰减，输出不硬削波；报告实际 frames、duration_seconds、peak、normalization_gain、音符/声音事件数。固定 seed 的噪声可复现（不承诺跨 CPU 位级相同）。
- 只支持有路径的文件输出，不向 stdout 输出二进制；默认不覆盖，拒绝符号链接/非普通目标，不允许覆盖乐谱输入（包括硬链接）。先完成渲染与编码验证，最后共享原子发布。

## 文件与职责

- `src/sound/score.rs`：NoteEvent{start_tick:u32,duration_ticks:u32,midi:u8}、Score{events,total_ticks,bpm}；`parse_score(text,bpm,repeat)->Result<Score>`、`parse_note(text)->Result<u8>`、`frequency(midi)->f64`、`encode_midi(&Score)->Result<Vec<u8>>`。
- `src/sound/synth.rs`：Instrument 枚举，Voice{start:f64,duration:f64,frequency:f64,end_frequency:f64,gain:f64,instrument:Instrument}，`render(voices:&[Voice],duration:f64,sample_rate:u32,volume:f64,seed:u64)->Result<Rendered>`；Rendered{wav:Vec<u8>,frames:usize,peak:f64,normalization_gain:f64}。纯函数，自己校验上限、finite 与 Nyquist，所有声部包络在时长内收尾。
- `src/sound/pattern.rs`：场景预设、鼓型、转换为 voices；避免将 CLI 参数解析塞入合成核心。
- `src/sound/cli.rs`：帮助、参数、乐谱读取、输出规划、dry-run、报告及安全发布。
- `src/sound/mod.rs`、`src/lib.rs`、`src/cli.rs`、`src/cli/help.rs`：模块和帮助接入。
- `tests/sound_cli.rs`：真实命令集成验证。
- `docs/tools/sound.md`、README、brand、AGENTS：完整使用说明和伙伴约定。
