# 时间转换工具 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在当前会话实现；用户要求未经确认不 commit、推送或发布。

**Goal:** 为 Kito 增加时间戳、日期时间、跨时区转换及可搜索的全球时区列表。

**Architecture:** `src/time/` 负责纯转换、时区解析与输出报告，独立 CLI 模块负责参数、环境变量及 stdout。`src/cli.rs` 仅增加领域路由。所有 Unix 计算使用整数，时区规则由内置 IANA 数据库提供。

**Tech Stack:** Rust、clap、chrono、chrono-tz、serde。

**Spec:** 本会话的需求及后续补充：时间戳与日期时间互转，设定或直接指定时区，毫秒/微秒等精度，全球时区列表，单个结果或 JSON 输出。下面记录由实现者确定的具体接口。

## Global Constraints

- 优先中文帮助、错误、文档和核心流程注释。
- 不 commit、推送、发布；当前仓库尚无提交，直接在已有功能分支工作，保留改前快照供 review。
- `kito time`，伙伴为品牌文档已有概念 Tiko；实现后同步明确能力范围。
- `now`、`from-timestamp VALUE`、`to-timestamp DATETIME`、`convert DATETIME`、`zones [FILTER]`。
- `--timezone` > `KITO_TIMEZONE` > UTC；`convert` 使用 `--from-timezone` 和必填 `--to-timezone`。带 offset 的输入优先使用自身 offset，显式源时区与它冲突时报错。
- 时间戳单位 `s/ms/us/ns`（兼容全称）；from 默认 auto，仅 1–10、13、16、19 位分别识别 s/ms/us/ns，其他位数要求明确指定；to 默认 s。
- 支持 IANA 和 `±HH:MM` 固定偏移，不改变操作系统时区。
- 无时区日期输入接受 `YYYY-MM-DD HH:MM:SS[.fraction]` 及 T 分隔形式；带 offset 接受 RFC 3339；小数最多 9 位，拒绝闰秒，DST 歧义/不存在时间报错。
- 默认友好文本；`--value-only` 与 `--json` 互斥。转换的 value-only 只输出一个结果，zones 输出每行一个名称。
- JSON 时间戳均为字符串；降低精度向负无穷取整，报告 `precision_lost`。日期输出使用 ISO 8601、显式 offset。
- zones 显示名称、偏移、缩写、统一参考时刻；可用 `--at` RFC 3339 指定参考时刻，记录 tzdb 版本。

## Review Focus

- 负时间戳的子秒部分不能因向零截断而错一秒。
- 纳秒超出 JavaScript 安全整数及 i64 范围时仍应保真或明确报错。
- 夏令时回拨/跳过与显式 offset 冲突不得静默选边。
- 环境默认不能覆盖带 offset 输入，也不能妨碍显式参数覆盖错误环境值。
- 历史时区含秒级偏移：展示与转换必须保留完整 offset，不能舍去秒。
