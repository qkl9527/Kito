# Kito Web UI 首版验证记录

日期：2026-10-29。环境：本机 macOS arm64。未执行 git commit、push 或发布。

## 交付范围

- `kito web` 启动回环地址服务，自动分配端口、打印会话链接并尝试打开浏览器；支持 `--port` 与 `--no-open`。
- 页面资源编译进二进制，保留已确认的工具小队视觉；无需 Node.js 运行环境。
- 八领域常用操作使用真实 CLI 子进程，包含输入、参数校验、任务状态、结果摘要、详细报告、文本复制、下载和图片/声音预览。
- 会话临时文件隔离、鉴权及 Host/Origin 校验、原始输入保护、资源预算、取消及失败结果不发布。

## 自动检查

以下命令均成功退出：

```sh
scripts/cargo-local.sh fmt --check
scripts/cargo-local.sh clippy --all-targets -- -D warnings
node --check web/app.js
KITO_OPENSSL=/opt/homebrew/opt/openssl@3/bin/openssl KITO_REQUIRE_BACKEND=1 scripts/cargo-local.sh test
scripts/cargo-local.sh build
```

全量 Rust 测试 278 项通过、0 失败、0 ignored。Web HTTP 集成测试 10 项通过，强制使用真实后端，没有因缺少后端而跳过；上面的 OpenSSL 路径仅是本机测试配置，未硬编码进程序。

Web 验证覆盖：

- 帮助案例顺序、内嵌页面、缺失/错误 token、Host/Origin 拒绝、路径穿越、非法字段与会话清理。
- PNG 压缩后真实像素与透明 RGB 保留，图片信息/元数据/转换；SVG、PDF、MVG、MSL 伪装 PNG 被拒绝。
- 二进制 Base64 下载逐字节一致；文本去重/大小写/统计、HTML/URL、Hash、UUID、时间转换真实结果。
- 音效 WAV 的 PCM 头与声音数据、旋律 MIDI 文件结构。
- 加密 Ed25519 生成、下载、重新上传、配对检查；错误口令不发布结果，报告不包含私钥或口令。
- 临时合成带声音视频，上传后去声，下载后 ffprobe 验证轨道与尺寸、FFmpeg 完整解码；原始素材字节不变。
- 伪装 `.mp4` 的 HLS 播放列表任务失败且没有下载；领域回归先复现可读取未选中片段，再确认格式白名单阻断。
- Unix 取消会终止整个进程组，后代无法写入 marker；持续运行命令的文本输出超限会被停止。符号链接与超额输出不能发布。

独立只读安全复核确认先前的媒体间接读取问题已封堵，未发现仍可具体触发的输入隔离/泄露 P1。

## 浏览器验收

使用真实本机服务、内嵌生产页面完成以下操作：

- 上传设计稿 PNG，快速无损压缩完成，结果可下载到浏览器下载目录。
- 输入「你好，Kito」得到字符统计 7；清空后输入和结果均移除。
- Base64 编码 `Kito`，查看真实文本 `S2l0bw==`。
- 时间戳 `0 s` 转换到 Asia/Shanghai，得到 `1970-01-01T08:00:00+08:00`。
- 使用临时测试口令生成 Ed25519；只提供私钥、公钥下载，不展示私钥正文。
- 合成 success 音效，得到 0.90 秒 WAV，预览显示音频控件。
- 在 390×844 窄屏展开导航、切换伙伴、计算 `abc` 的 SHA-256；结果自动获得焦点，长内容换行。
- 检查页面控制台没有 error；测试结束后恢复浏览器原始尺寸。

截图：`web-ui-home.jpg`、`web-ui-mobile.jpg`，与本记录同目录。浏览器最终保留全新会话首页，前述测试临时文件随服务重启清理。

## 边界

- 只验证了上述本机环境；Windows Job Object 清理路径与 Linux 未作本机运行验证。
- 首版提供常用操作，不是完整 CLI 高级选项的逐项映射；外部编解码器支持范围仍取决于实际安装。
- 任务输出预算为定期检查，不是操作系统级硬配额；SIGKILL 或机器异常退出不保证清理临时目录。
- `docs/design/web-ui/` 保留原设计稿，正式功能入口为 `kito web`。
